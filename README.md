# Привет! Я начинающий QA Engineer 🛡️

Я живу в Санкт-Петербурге и активно развиваюсь в сфере ручного (Manual) тестирования веб- и мобильных приложений. Постоянно прокачиваю технический стек, чтобы не просто «кликать по кнопкам», а глубоко понимать логику работы систем и эффективно локализовать баги.

### 🛠️ Мой стек и инструменты

* **Тестирование (QA):** создание тест-кейсов, чек-листов, оформление понятных баг-репортов, применение техник тест-дизайна (классы эквивалентности, граничные значения).
* **Инструменты разработчика:** Chrome DevTools (анализ вкладок Network и Console, инспектирование элементов, проверка адаптивности).
* **Тестирование API:** Postman (отправка GET/POST/PUT/DELETE запросов, работа с параметрами, заголовками и телом запроса).
* **Базы данных:** SQL (базовые запросы SELECT, фильтрация через WHERE, сортировка ORDER BY, работа со структурами данных).
* **Техническая база:** HTML, CSS (понимание структуры веб-страниц для быстрого поиска причин визуальных дефектов).
* **Контроль версий:** Git & GitHub (базовые команды, работа с ветками, ведение портфолио).
